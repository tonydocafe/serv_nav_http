### Módulo HTTP (http.c / http.h)

Criando e enviando as resquisiçoes HTTP GET.
Recebendo as respostas HTTP

### Módulo Rede (rede.c / rede.h)

Implementa a criação de sockets, resolve  DNS 
e estabelece a conexão com servidor.

### Módulo URL (url.c / url.h)

Realiza a separação das informações da URL, como host, caminho e porta de comunicação,
disponibilizando esses dados para os demais módulos do sistema.
